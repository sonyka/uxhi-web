MobileNavMenu from web. Use via `window.UXHICon2026.MobileNavMenu` (bundle loaded from the root `_ds_bundle.js`).

## Examples

### RestingPill

```jsx
() => (
  <PhoneFrame>
    <MobileNavMenu />
  </PhoneFrame>
);

/**
 * Tapped. One flat tier: both past years, UXHI, and the mailto — the mobile
 * footer's whole nav in one card, popping upward off the bar.
 */
```

### OpenMenu

```jsx
() => (
  <PhoneFrame open>
    <MobileNavMenu />
  </PhoneFrame>
)
```
